Methods

Each permutation is frozen once and shared unchanged between repeats. Input checks preserve the complete read-record multiset, including duplicate multiplicities and qualities. Sequence comparisons ignore names, output order and strand while retaining duplicate copies and sequence changes. Ends are retained in the primary comparison. The independent circular view allows rotation only for tool-reported circles; unknown topology leaves that view unassessed. Plassembler comparisons include final plasmids and its verified retained chromosome. Neither signature uses the reference.

Variation within a fixed read order prevents attribution of between-order differences specifically to read order. Missing executions leave the comparison incomplete.
